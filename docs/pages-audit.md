# pages/*.yaml — audit report

> **Status: done.** This is the audit that started the work; the findings are
> all resolved. The templates now validate clean (44 templates, 0 errors),
> the map is generated from them, and `pages/*.yaml` is no longer inert
> reference material — `remote/scripts/generate_map.py` turns it into
> `remote/Maps/Nuts/Nocturn.remotemap`. See `docs/pages-templates.md` for
> the current workflow, and `docs/pages-repair-plan.md` for what the repair
> was.
>
> Two findings below are now known to be wrong and are corrected elsewhere:
> the scope names are resolved against `remote/remote-info/` (not only the
> factory maps), and `remote/remote-info/` turned out to be far richer than
> the factory maps, so most of the "not remotable in Reason" targets in §4
> were real parameters that only needed **renaming**.

Generated by `remote/scripts/audit-pages.ps1` against Reason's factory maps in
`<ProgramData>\Propellerhead Software\Remote\Maps`.

## 1. deploy.ps1 does not use these templates

`remote/scripts/deploy.ps1` copies a hand-written, single-scope
`remote/Maps/Nuts/Nocturn.remotemap` into Reason's Remote folder.

Nothing in the repository reads `pages/` or any `.yaml` — no PowerShell
script, no C# source, no JSON, no Lua, no csproj. The templates are currently
inert reference material.

The shipped map contains exactly **one** `Scope` block:

```
Scope	Propellerheads	Reason Main Mixer Channel
```

## 2. The templates describe a different model from the shipped map

For the mixer scope alone:

| | Shipped map (verified on hardware) | `reason-main-mixer-channel.yaml` |
|---|---|---|
| Pages | 4 — Mixer, Dynamics, EQ, FX | 6 — Mixer, EQ, Dynamics, Sends 1-4, Sends 5-8, Insert FX |
| PermaBar key → page | Mix=15, User=Dynamics, Instr=EQ, FX=FX | Mix=Mixer, User=EQ, Instr=Dynamics, Learn=Sends 1-4, View=Sends 5-8, FX=Insert FX |
| Dials used | all 8 on pages 2 and 4; E1/3/5/7 on 1 and 3 | E1/3/5/7 only |
| Sends vs Insert | merged into one FX page (4 sends max) | separate Sends 1-4, Sends 5-8, Insert FX |

Note the page assignments are **swapped** (USER→EQ and INSTR→Dynamics in the
template, versus USER→Dynamics and INSTR→EQ in the shipped map). These are two
different paging designs, not a small edit apart.

## 3. Scope-name mismatches (4 templates)

Every other template names a scope that exists in Reason's map set. These four
do not, so their targets cannot be validated at all:

| Template | Declared model | Reality |
|---|---|---|
| `arpeggio.yaml` | `se.propellerheads.Arpeggio` | real scope is `RPG-8 Monophonic Arpeggiator` |
| `note-echo.yaml` | `se.propellerheads.NoteEcho` | not a scope in the factory set |
| `scales-and-chords.yaml` | `se.propellerheads.ScalesAndChords` | not a scope in the factory set |
| `morfin.yaml` | `com.groovymelon.MorfinXF` | third-party Rack Extension; scope only appears when the RE is installed |

## 4. Invalid remotable targets (14 templates, 205 occurrences)

| Template | Bad targets |

| `humana.yaml` | 1 |
| `radical-piano.yaml` | 1 |

These are not parser artefacts. Verified examples:

* `unison-16.yaml` references `Detune 0`, `Dry/Wet 0`, `Enabled 0`,
  `Input Gain`, `Pan`. The `UN-16 Unison` scope exposes exactly four real
  signal targets: `Detune`, `Dry/Wet`, `Voice Count`, `Enabled`. The `… 0`
  names are **display-group strings** (`"Detune"` followed by a field
  separator in the factory map), not targets.
* `synchronous.yaml` references `Filter Lag`, which exists in **no** scope in
  the whole factory set.
* `dmfc.yaml` references `Compressor_Ratio`, also present in no scope
  (underscored `snake_case` names are not Reason target names).
* `Redrum Drum Computer` exposes 441 target strings, but most are display
  text such as `"  <  "`, `" Mode"`, `""` — the factory map drives the panel
  display through `Display=ParaName` items. `Drum 1` and `Drm10` are real;
  `"  <  "` is not.
* `Monotone` has **no** `Map` entries in the factory set at all, so the
  template's 32 targets were written against a device whose map is not
  present here.

Names like `Pan`, `Level`, `Solo`, `Mute`, `Volume`, `Input Gain`, `Algorithm`
and `On` do exist in the global target set — but not necessarily in *this*
scope. Targets are per-scope, and a name that is valid on a mixer is not
automatically valid on a drum machine.

## 5. Duplicate targets within one scope — 470 occurrences

Reason refuses to load a surface if the same remotable item is mapped twice
inside one scope (`remotable item already mapped in this scope`). The audit
found **470** duplicate target occurrences across the templates.

Some duplication is intentional and structural — a control set repeated per
page (the Akai `Knob 1 A` / `Knob 1 B` idiom) is exactly that, and it is
represented here by the same `target` appearing under several pages. The
shipped map handles this by duplicating the *item set* per page with distinct
item names while repeating the target name.

So this count is **not automatically a defect**, but it does mean the
templates cannot be emitted naively: the generator must produce one distinct
item name per (control, page) while keeping the target shared.

## 6. What this means for a generator

A `pages/*.yaml` → `.remotemap` generator is buildable, and the request to
cover all ~40 scopes in one map is fine. But before it can be trusted, these
problems have to be resolved in the templates themselves:

1. Fix the 4 scope-name mismatches (§3).
2. Fix or remove the 205 invalid targets (§4) — drop the display-only
   names, drop `snake_case` names, correct `ecf-42.yaml`.
3. Decide the paging model. The mixer template says 6 pages; the shipped,
   hardware-verified map says 4. A generator must pick one, and switching to
   the template's model invalidates the verification already done.
4. Teach the generator to emit per-page item names (§5).
5. Four templates (`monotone`, `morfin`, plus the two unknown scopes) can
   only be validated on a machine where those devices/REs are installed.

Until (1) and (2) are done, the audit cannot distinguish "template is wrong"
from "device is absent", and the generator would emit a map that Reason
rejects wholesale.
